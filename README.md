# 🐍 Curso de Python 2026 - FEA.dev

Bem-vindo ao repositório oficial de organização e produção de materiais para a **estruturação do Curso de Python do FEA.dev para 2026**. Este repositório centraliza os roteiros, *notebooks* e diretrizes para a gravação das novas aulas.


---

## 📚 Ementa do Curso (Planejamento 2026)

A estrutura foi condensada para evitar repetições e otimizar o tempo.

### Aula 1: Fundamentos

* Tipos de dados fundamentais e palavras reservadas.
* Operadores aritméticos (+, -, *, /, //, %, **).
* Operações com Strings.
* Inputs e Outputs .



### Aula 2: Lógica de Controle

* Condicionais (if, elif, else) e Booleanos.
* Operadores Lógicos (and, or, not) e de Comparação (>, ==, !=).
* Operador `in` e Identidade (`is`).
* Loops: `while` e `for` (com `break`).
* Introdução a Listas .



### Aula 3: Estruturas de Dados

* Tuplas, Dicionários e Sets.
* Métodos nativos para estas estruturas com exemplos práticos .



### Aula 4: Modularização e OOP

* Definição de Funções, `*args`, `**kwargs`.
* Definição de Classes e Objetos (Atributos e Métodos).
* Bibliotecas nativas (math, time) .



### Aula 5: Introdução a Dados (Numpy e Pandas)

* Instalação (Pip) e Numpy.
* Pandas: DataFrame e Series.
* Carregamento de dados (Excel, CSV).
* Métodos de resumo (`head`, `describe`, `info`) e fatiamento (`loc`, `iloc`).




### Aula 6: Manipulação Avançada de Dados

* Agregação (`sum`, `mean`, `groupby`, `agg`).
* Limpeza de dados (`dropna`, `fillna`, `astype`).
* Filtragem booleana e Concatenação (`merge`, `concat`).
* Análise (`diff`, `pct_change`, correlação) .
* Métodos gráficos básicos (`hist`, `plot`, `scatter`) .
